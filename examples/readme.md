# `SLiMfast`'s examples

Inside the `examples` directory you will find several examples of runs of the `SLiMfast` pipeline.

## Examples

### Example 1 - Running the entire `SLiMfast` pipeline on one protein calling each tool separately

In the `example1_pipeline_steps` directory, you will find the scripts and input files used to run `slimfast_get_structures`, `slimfast_get_alphafold`, `slimfast_get_homologs`, and `slimfast_find_slims` on the human protein Bcl-2, whose UniProt ID is `Q10415`. Furthermore, you will find all the output files generated by the different tools. A `readme.txt` file can be inspected to follow the steps performed.

### Example 2 - Running the entire `SLiMfast` in one go for multiple proteins

In the `example2_pipeline_onego` directory, you will find the scripts and input files to run the `slimfast_run_pipeline` tool on a set of proteins (and their associated SLiMs). You will also find the output files produced by the run, and a `readme.txt` file detailing how the run was performed.
